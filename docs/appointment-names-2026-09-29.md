# שמות פגישות — החלטה ומימוש 29.09.2026

אישור דוד: ״מעולה לך על זה״.

- פגישת המלצות → בדיקת תיק פנסיוני.
- המשך טיפול נשאר ללא שינוי.
- פגישת שירות / פגישת שירות פנסיונית → פגישת שירות שנתית.

עודכנו יצירת הפגישות, תצוגת פגישות קיימות ב־CRM, כותרת אירועים חדשים בגוגל ונושא מייל סיכום חדש. נשמרו מזהי האירועים, מועדים ונושאים אישיים; זיהוי תאריך הפגישה תומך בשם הישן והחדש. אין שינוי או שליחה חוזרת של מיילים/אירועים קיימים בגוגל.

עיתוי מאושר לפי מסמך ההסכמות: שנה מפתיחת הגיוס הראשון, פגישה אחת לכל הלקוח. בקוד הקיים saveDecision מפעיל scheduleService בשמירת החלטת ביצוע ראשונה, לא בהוספת ליד או בסיום כל המוצרים. גיוס נוסף אינו מזיז או משכפל פגישת שירות פתוחה. העיתוי לא שונה בתיקון שמות זה. בחירת חלון מתחשבת בפגישות השמורות ב־CRM, ולא אומתה בדיקת free/busy מול כלל יומן גוגל. הזמנת משתתפים במייל עדיין אינה נשלחת בסנדבוקס.

בדיקות: appointment-names, mail, calendar, followup-ui ו־crm-layout עברו; build עבר. בדיקות חיצוניות מדומות בלבד, ללא משלוח מיילים.
