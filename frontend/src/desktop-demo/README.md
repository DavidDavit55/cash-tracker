# דוגמת דסקטופ NETWORTH

דוגמה אינטראקטיבית על בסיס הקלטות המסך שסופקו, עם דגש על גרסת הדסקטופ.

## הפעלה מקומית

מתיקיית `frontend`:

```sh
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

פתחו: http://127.0.0.1:5174/desktop-demo.html

## מה כלול

- תפריט צד מתכווץ ומסכי מבט מהיר, חסכונות, ביטוחים, המלצות, שיתוף ופרופיל.
- השוואת חיסכון עם מתג התאמה לשכר וסיכום.
- חלון פרטי פנסיה עם גרפי הפקדות ותשואות, בחירת תקופה ודמי ניהול.
- צ׳אט עם תשובות מוכנות מראש.
- התאמה בסיסית למסך צר וניווט תחתון.

הדוגמה משתמשת בנתונים לדוגמה בלבד. היא אינה שולחת בקשות ל־Backend, ל־Railway או לשירות AI. עריכת פרופיל נשמרת בזיכרון הדף בלבד ונמחקת ברענון. קישור השיתוף הוא קישור המחשה ל־example.com.

זו כניסת Vite נפרדת. אין שינוי ב־App.jsx, בנתיבי האפליקציה, במנגנון ההתחברות או בהגדרות הפריסה. הפקודה הרגילה של build עדיין בונה את האפליקציה המקורית בלבד.

בדיקות: ESLint לקבצי הדוגמה, בניית Vite בזיכרון עם desktop-demo.html ככניסה, ובדיקת התצוגה והפעולות בדפדפן.
